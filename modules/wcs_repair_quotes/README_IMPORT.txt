WCS Excel Import

1. วางโฟลเดอร์ modules/wcs_repair_quotes ทับของเดิม
2. ต้องเปิด PHP extension: zip และ simplexml
3. เข้าเมนู ใบเสนอราคาซ่อม WCS แล้วกด นำเข้าจาก Excel
4. รองรับไฟล์ .xlsx รูปแบบเดียวกับใบเสนอราคา WCS ตัวอย่าง
5. ระบบจะอ่านข้อมูลและเปิดฟอร์มให้ตรวจสอบก่อนบันทึก


การนำเข้ารูปภาพจาก Sheet
- หมายเลขเครื่อง
- รูปอะไหล่เสีย
- ใบรายงาน

ระบบจะบันทึกรูปไว้ที่ uploads/wcs_repair_quotes/ และเชื่อมกับใบเสนอราคาในตาราง wcs_repair_quote_attachments
สำหรับระบบที่ติดตั้งแล้ว ให้ Import upgrade_add_excel_images.sql เพิ่มเติม

แก้ไขเพิ่มเติม:
- รองรับ Default Namespace ในไฟล์ .rels ของ Excel
- ใช้ชื่อไฟล์รูปภาษาอังกฤษเพื่อไม่ให้ถูกปฏิเสธตอนบันทึก
- รักษารูปเดิมไว้เมื่อเปิดแก้ไขใบเสนอราคา
